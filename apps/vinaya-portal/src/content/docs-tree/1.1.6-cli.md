# CLI — definition

Summary: The vinaya commands you run, grouped by job: install and maintain, gates, the Log, Studio and rulings, and trying it out. Commands the Operator and the agents call are not listed.
Parent: CLI
Badges: Reference · vinaya · npx

Install once with `npx @attalabs/vinaya`. After that, the `vinaya` command runs in the repository.

```bash
npx @attalabs/vinaya
```

This page lists only the commands you run yourself. The Operator and the agents call other commands as they work; those are not listed.

```callout-note
The Vinaya process adds three commands you run inside your agent: `/vinaya architect`, `/vinaya planner` and `/vinaya operator`. See [Vinaya process commands](/docs/start/cli/vinaya-process).
```

## Install and maintain

```commands
quickstart
init
upgrade
doctor
eject
```
