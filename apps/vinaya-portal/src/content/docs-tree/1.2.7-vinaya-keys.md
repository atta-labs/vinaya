# Vinaya keys — definition

Summary: The keys the Vinaya process declares in vinaya.config.json: its roles, brief shape, reviews, checks and limits.
Parent: The Vinaya process
Badges: vinaya.config.json · Process keys · Reference

`vinaya.config.json` is one committed file that says how a repository is governed. It selects and parameterizes; it never loads code. Some keys belong to the harness and the rest to the process.

The keys on this page belong to the Vinaya process, not the harness. A team running its own process declares its own instead. The harness keys are in [Configuration](/docs/features/configuration).

```callout-note
For an unattended run, `reviewPolicy` and `securityScan` are read from the default branch, never from the pull request, so a change cannot rewrite its own rules. See [Trust](/docs/features/configuration/trust).
```

## The process keys

```config-keys
process
```
