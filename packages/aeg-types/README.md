# @attalabs/aeg-types

Shared TypeScript types for the AEG (Agentic Engineering Governance) engine: tranches, tasks, derived status, forge facts, and the check/verdict shapes the other engine packages exchange.

Zero runtime dependencies. Published as TypeScript source (`main` points at `./src/index.ts`) — consume it with Bun or a TS-aware bundler, not plain Node.

Part of the fixed release group `@attalabs/aeg-types` / `@attalabs/aeg-forge-state` / `@attalabs/aeg-core` / `@attalabs/vinaya-sources` / `@attalabs/vinaya`: all five always share one version.
