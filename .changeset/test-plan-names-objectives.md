A task Issue is refused unless each objective has named proof and each Test plan line names the objectives it proves. A fenced line ends with its expected observable and then the objective ids it proves in parentheses; a principal or live item carries its ids in one code span. The `unit-tests-only` sentinel is no longer accepted for a task Issue, and the live check ignores the ids when it reads an item's command.
