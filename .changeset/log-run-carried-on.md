A run's records link to it whichever process writes them: a later process carries on a started run, writes its run, round, pause and person spans whole from the start in the local copy and sends the alive event, and merged, reverted and incident link to the handle's run by default. The handle gains `change.closed` for a change closed without merging, and `person.asked` takes an optional how-to-answer text.
