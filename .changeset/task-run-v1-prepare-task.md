Adds `vinaya task brief <tranche> <n>`, preparation only: it renders and freezes the task's brief as the same `aeg:brief:v1` Issue comment `task dispatch` posts, and starts no agent under any circumstances. `task dispatch` is deprecated in favor of `task brief` (preparation only) and the forthcoming `task run` (the full unattended loop), kept for a documented compatibility window with identical observable behaviour.
