`task switch` restarts a tranche task through its tranche address, so the started run prepares it instead of refusing it as a tranche Issue on the backlog path. A `--issue` request naming a tranche-labeled Issue resolves to that address first, an address no run accepts changes nothing, and a background start that fails after the checkpoint moved reports the folder it went to and the command that starts the run.
