Forge comment markers are now written with the `vinaya:` prefix: the frozen brief, the Developer's round and stop records, the loop's published, paused and unpushed-work-resume records, the Principal's rulings, the objectives versions and the deferred-findings tracker. Every reader still accepts the earlier spelling, so closed Issues and pull requests and an in-flight run's earlier comments read the same; ruling ordinals, brief versions and objectives versions count both spellings together, so no number is reused, and a deferred-findings tracker opened under the earlier marker stays the one tracker for its pull request. `vinaya task status` finds a frozen brief posted in either spelling with one search.
