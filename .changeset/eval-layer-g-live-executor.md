Step one of the evaluation program runs a layer-G trial live: it renders the suite's development neutral case with the Vinaya renderer, runs the named role through the same staged, sandboxed dispatch as a layer-P trial, and grades the extracted neutral outcomes with the generic graders alone. Every trial result and suite-and-adapter run reports its process layer and renderer version, and a practice run can select one adapter (`--adapter`) and a few cases (`--cases`).
