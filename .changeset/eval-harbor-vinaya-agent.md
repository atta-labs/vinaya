Every layer-G role case of the evaluation harness can run as a Harbor `0.24.0` trial of a `vinaya` agent: a converter writes one Harbor task folder per case, whose image holds the case repository at its real base commit with every evaluation case file and held-out file absent, the agent runs the Vinaya role in container mode with the subscription login alone, and a bundled verifier grades the trial with the generic graders.
