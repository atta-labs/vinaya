A transient GitHub error no longer stops an unattended loop for a person. A red gate counts as a repeated failure only when a Developer attempt finished since the last one. The watcher retries a failed bare retry within the infrastructure budget. A host that cannot reach GitHub waits for the connection without spending that budget. The dispatch gate reports a failed open-Issues query as an infrastructure failure, not as an unarchived prior tranche.
